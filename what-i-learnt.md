# What I Learnt in Week 3

## Command line
- `pwd` shows which folder I am in, `ls` lists files, `cd` moves between folders.
- `mkdir -p` creates nested folders in one go, and `touch` creates empty files.
- `find` searches for files by name, and `grep` searches inside files.
- I wrote a shell script (`new-project.sh`) that builds a project boilerplate automatically.
- I learned to check my location with `pwd` before running commands. Running them in the wrong folder gave me errors.

## Git and GitHub
- `git status` shows what has changed.
- `git add`, `git commit` and `git push` save my work to GitHub.
- A good commit message describes the change, for example `feat: add Week 3 daily challenges`.
- I add specific files instead of using `git add .` so unwanted files don't get committed.

## Challenges I faced
- My commands ran in the wrong folder at first. I fixed it by checking `pwd` and moving into my repo.
- My repo is inside OneDrive, so the path was different from what I expected.

## What I want to improve
- Practise branching and resolving merge conflicts until they feel easy.
- Get comfortable with the terminal without copying commands.
