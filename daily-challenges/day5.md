# Day 5

## Challenge
Create aliases for common commands.

## Aliases I created
`alias gs="git status"`
`alias ll="ls -la"`
`alias gl="git log --oneline"`

## What it does
An alias is a shortcut, so `gs` runs `git status`. I saved them in `~/.bashrc` and reload with `source ~/.bashrc`.

## Problem I faced
The aliases did not work straight away. I had to reload the file with source ~/.bashrc.
