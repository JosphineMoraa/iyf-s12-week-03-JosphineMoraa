# Day 1

## Challenge
Create a folder structure using only the terminal.

## Commands I used
`mkdir -p day1-demo/css day1-demo/js day1-demo/images`
`ls -R day1-demo`

## What it does
`mkdir -p` makes nested folders in one go. `ls -R` lists every folder and file inside.

## Problem I faced
My commands ran in my home folder instead of my repo, so the folders were created in the wrong place. I fixed it by checking pwd and moving into my repo with cd.
