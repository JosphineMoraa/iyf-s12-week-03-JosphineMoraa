# Day 3

## Challenge
Write a script that creates a project boilerplate.

## What I did
I wrote `new-project.sh` in the repo root. Run it with `bash new-project.sh my-site`.
It creates `css`, `js` and `images` folders, `index.html`, `style.css`, `app.js` and a `README.md`.

## Problem I faced
The script first ran outside my repo and Git said not a git repository. I learned to check my location before running a script.
